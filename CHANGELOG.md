# Changelog

## Обновление v1.0.0 (2026-11-22) — производительность

- Мониторинг CPU/RAM/GPU вынесен в `SystemMonitorWorker` (QThread): тяжёлый опрос
  WMI/nvidia-smi больше не блокирует GUI. Максимальная задержка событий снизилась
  с ~4 с до ~0.12 с.
- Иконки и пути программ кэшируются; поиск с debounce 140 мс; рекурсивный обход
  Program Files при поиске `.ico` убран. Фильтрация списка ускорена ~в 2.4 раза.
- Интервал опроса GPU увеличен до 10 с (результат кэшируется).

## v1.0.0 (2026-11-21/22)

Первая публичная сборка WinBoost Pro.

### Функции

- Вкладки: Главная, Очистка, Службы, Программы, Автозагрузка, Твики, Настройки.
- Очистка кэша Chrome/Яндекс/Temp/эскизов с проверкой занятых процессов.
- Управление службами с профилями и проверкой зависимостей.
- Деинсталлятор программ с поиском и очисткой «хвостов».
- Автозагрузка из WMI/реестра/Планировщика/shell:startup.
- Пакетные «Продвинутые твики» с авто-бекапом, предупреждением о BSOD и перезагрузкой.
- Резервные копии служб и автозагрузки в JSON + восстановление.

### Исправления после релиза

- `human_size()` больше не падает на `inf`/`nan` при сканировании.
- Вкладка «Программы»: колонка «Путь к файлу», рабочая кнопка «...»,
  утилиты DDU и NVCleanstall, запуск утилит.
- Отображение имени видеокарты через WMI (AMD/Intel/NVIDIA), кэширование опроса GPU.
- Резервные копии падают в `%LOCALAPPDATA%`, если папка приложения доступна только для чтения.
- Корректная кодировка вывода `powercfg`/`schtasks` (OEM cp866).
- UAC-перезапуск при запуске без прав администратора.
